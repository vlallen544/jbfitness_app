JB FITNESS — CLIENT PREVIEW

If you downloaded JB_Fitness_Client_Preview.zip, extract it first.

1. Copy JB_Fitness_Client_Preview.apk to an Android phone.
2. Open the file and allow installation from that source if Android asks.
3. Open JB Fitness. Explore the feature walkthrough using Next/Back/swipe, or tap Skip intro.
   The sample account then opens automatically; no login is needed.

Explore Today, Workouts, Plans and Profile. Today also links to habit grids,
the food diary, body progress, coaching, trainer feedback and session history.

The banner identifies this as an OFFLINE DEMO. All records are sample data.
Habit checkmarks, workout logs and profile edits last only for the current
app session. Force-stop and reopen the app to return to the starting samples.
Please use sample information when trying the forms.

Nutrition and measurements are sample read-only records. Live AI, payments,
video calls, exercise videos and uploads are not connected in this preview.
This build is for reviewing the design and navigation. It is not a production
release. No backend or internet connection is needed for the sample flows.

This APK is for Android phones, not iPhones. Installation and camera/gallery
behavior still need checking on a physical Android device.
